Star Catcher, a tiny browser game an AI agent built from a single prompt: catch the falling stars with the basket, three lives, score as you go. The entry's video shows the prompt, the agent working, and the finished game running in a browser — then the make.fun referral end card.

## Run it

```sh
Open game/index.html in any browser. Add ?demo=1 to watch it play itself.
```
